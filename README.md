# Product Card UI

A dynamic, vanilla JavaScript product card interface that fetches data asynchronously from a local JSON file. This project focuses on clean DOM manipulation, performance optimization, and user interactions without relying on external frameworks.

## ✨ Features
- **Async Data Fetching:** Loads product data dynamically using the Fetch API.
- **Dynamic Rendering:** Utilizes HTML `<template>` and `cloneNode(true)` for efficient, scalable DOM generation.
- **Interactive UI:** 
  - Thumbnail image switching.
  - Color option selection with active state management.
  - "Add to Cart" button with state change and disabled prevention.
  - Dynamic removal of product cards from the DOM.

## 🛠️ Tech Stack
- HTML5 (Semantic markup, `<template>`)
- CSS3 (Custom Properties / CSS Variables, CSS Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- JSON
